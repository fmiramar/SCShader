## Failures, corrections, and remaining observations

The first package attempt linked the renderer and completed the notice inventory
but exited 127 because the external `zip` command was absent. The Linux packager
now uses Python's standard ZIP writer, already available as a prerequisite.
The corrected archive preserves its layout and executable mode. No dependency
upgrade or renderer workaround was needed for native linking.

The first Wayland help run passed 17 cases and failed the README Pattern case:
`help-wayland-01/readme-pattern.log` records an `E_LATE_EVENT` of **58.589 ms**.
The default scheduling lookahead is 20 ms. Three focused reruns of the unchanged
case passed (`pattern-repeat-*-console.log`), followed by an unchanged full
18-case pass (`help-wayland-02/`). The cause of the isolated timing excursion
was not established. It remains a recorded timing observation; no assertion,
diagnostic tolerance, default latency, example, or graphics selection was changed
to obtain those passes. Longer timing stability is not established by reruns.
