## Reproduced issues and changes

- Windows detection used `Platform.name`, the class name rather than the OS.
  `ShaderServer` now uses `thisProcess.platform.name` for executable discovery,
  PATH splitting and child termination. The ZIP contains this fix.
- Explicit `--adapter` and `--power-preference` select a unique compatible
  adapter, report the driver and retain selection during recovery. No fallback.
- Packaging accepts explicit Python, retains previous artifacts, validates native
  target/header metadata and excludes AppleDouble files. Source ZIP checks handle
  Windows path normalization and preserve CRLF license bytes.
- The installer validates metadata/hash and backs up previous installations
  outside Extensions. The user ran it successfully; no previous extension existed.
- Initial acceptance failed on startup UDP `WSAECONNRESET`; handshake retries
  only that startup condition within its timeout. A subsequent failure came from
  slow PowerShell memory sampling. Native read-only working-set queries replaced
  it, with exited-process checks. Negative evidence is retained.
- SC runner state isolates Archive, SCDoc and large-SynthDef files. FFT's attempted
  default SynthDef-cache write was denied by the sandbox, not a GPU/DSP failure.
- Opt-in `--audio-output-device` / `--audio-input-channels` configure only owned
  test servers. The default WASAPI microphone/Bluetooth-output pair failed.
  Rechecks use Realtek WASAPI output, no hardware inputs, 48 kHz. No system/IDE
  audio settings were changed.
- The lifecycle test depended on POSIX `touch`. It now edits only a generated
  shader fixture and has an internal timeout. The original timeout left renderer
  PID 21880 alive; exact path, start time and test port were verified before
  PID-scoped cleanup. Taskkill-based harness cleanup still needs hardening for
  failed/abnormal parents.
- Unrestricted user-class compilation found the installed classes, but the
  unrelated PbindFx startup hook attempted an external write denied by this
  session's sandbox. `sc-installed-01/` remains failed evidence; an isolated
  configuration using the actual installed extension passes in `sc-installed-02/`.
  No other extensions or user settings were modified.
